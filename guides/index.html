This silent, 4 minute 35 second tutorial shows version 1.0.0 (4) in Xcode’s iPhone Simulator using local Demo replies. It covers onboarding, chat, characters, sessions, AI-sharing permission and local data deletion. It does not show a physical device or a live AI conversation.

Open or download the walkthrough (MP4, 9.2 MB). The instructions below also describe the controls shown in the silent recording.

1. Try it without an account

  1. Launch Lantern Companion and tap Get started.
  2. Choose Cocoa or Shino, then tap Choose voice.
  3. Tap Skip — use basic voice. You can download the optional voice later.
  4. Tap Explore Demo mode and send a message.

Demo uses fixed replies stored in the app. It needs no Lantern account, API key or sample file. Connected AI provides generated conversations.

2. Connect OpenAI

  1. Open Settings → AI provider and select OpenAI.
  2. Leave Model (optional) blank to use GPT-4.1 mini. The app sets the endpoint automatically.
  3. Enter your OpenAI API key and tap Save API key.
  4. Read the recipient and data-sharing explanation. Enable Allow AI data sharing if you agree.
  5. Tap Done, return to Chat and send a message.

Your provider account needs API access and available credit. Provider charges are separate from Lantern. A quota or credit-balance error must be resolved in that provider account; retrying the same key will not restore credit.

When connected, the provider receives recent messages from the current session and your response preferences. Review the privacy policy before sending personal information. Keep API keys out of screenshots, recordings and support messages.

For an OpenAI-compatible service, choose the custom provider option and enter its HTTPS base URL, model ID and key. Use the exact details from that provider. The app adds /chat/completions to the base URL.

3. Keep conversations organized

  • Use Live to see the animated companion and Chat to read the conversation.
  • Open the clock/history button, labelled Sessions and preferences, then select New chat.
  • Tap a saved session to reopen it. Swipe left on a session or press and hold it to Rename or Delete.
  • In Settings, edit Response preferences to describe how you want replies written. These apply across sessions and are included in connected requests. Demo replies remain fixed.
  • Change the character using Settings → Companion → Avatar.

4. Use spoken replies and voice input

In Settings → Companion, enable Speak replies and tap Preview voice. Basic Apple speech works without the optional pack.

For natural voice, go to Settings → Offline voice → Download Supertonic voice pack, read its terms and choose Agree and download if you accept. The download is about 399 MB. Once ready, enable Prefer natural voice. Speech is generated on your device.

If a download is interrupted, use its pause/resume or retry controls. Wi-Fi is the default; Allow mobile data for downloads enables cellular use. Remove the pack in Settings to reclaim space.

Voice input needs Microphone and Speech Recognition permission plus support for on-device recognition in your device's language. If unavailable, type your message. Microphone recordings are not sent to the AI provider; a transcript you choose to send is treated as chat text.

5. Manage your data

  • Turn off Allow AI data sharing to stop future connected requests, or select Demo.
  • Choose Remove saved key while the relevant provider is selected. Removing the app alone does not reliably remove Keychain items.
  • Choose Delete chat history and confirm Delete History to erase all local sessions and messages. This cannot be undone.
  • Clear response preferences separately in Settings, and use Remove voice pack to remove downloaded voice files.
  • Data already received by an AI provider must be managed with that provider. Local deletion does not delete provider-held data.

Lantern does not create a user account, so there is no Lantern account-deletion flow.
