# Lantern Companion public website

Support, getting-started guides, privacy policy, terms and third-party license notices for the Lantern Companion iOS app.

Website: https://gank8818-bit.github.io/lantern-companion/

GitHub Pages publishes the `main` branch at its root. All navigation uses relative paths so this site can also be served from a project subdirectory. No build tools or server are required.

Only public website content belongs in this repository. API keys, App Store credentials, reviewer credentials, app archives and private user data must never be added here.
